# Sistema de Registro de Aprendices SENA

## Descripción del proyecto
Este proyecto desarrolla un sistema de consola en Python para registrar, consultar, listar, filtrar y eliminar aprendices del SENA. La información se guarda en un archivo JSON para conservar los datos entre ejecuciones.

## Objetivo de la actividad
Implementar un CRUD básico en Python, aplicando conceptos de diccionarios, funciones, validaciones de entrada y persistencia de datos.

## Datos del aprendiz

## Funcionalidades
- Registrar aprendiz
- Consultar aprendiz por documento
- Listar todos los aprendices
- Filtrar aprendices por número de ficha
- Eliminar aprendiz por documento
- Persistencia en archivo JSON

## Ejecución
Ejecuta el siguiente comando en la raíz del proyecto:

```bash
python main.py
```
